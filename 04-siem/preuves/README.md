# preuves/

Relevés horodatés qui soutiennent la matrice : sorties de `verifier-siem.sh`, relevés des champs
ECS réellement remplis par chaque intégration, résultats des requêtes de rejeu.

**Jamais de données brutes** : aucun export d'événements de la VM Windows (sa navigation est
dedans), aucun secret (mot de passe, jeton, clé d'API), aucune capture d'écran où l'un d'eux
serait lisible.
